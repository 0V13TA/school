# LAB 9: Final Project (CA) - 2 weeks

## Project Title: Student Record System in C programming.

### Project Description:

You are tasked with creating a simple Student Record System in C that allows
users to manage student information. The program should provide the
following functionality:

    1. Create a new C project in our preferred development environment
       (JetBrains Clion).
    2. Write a program that displays a welcome message and allows the user to
       enter their name. The program should then greet the user with their
       name.
    3. Implement data storage for student information, including name, roll
       number, and marks. Use appropriate data types for each field.
    4. Add a feature that allows users to input a student's marks and then
       displays whether the student has passed or failed based on a passing
       threshold (e.g., marks above 40 are considered passing).
    5. Implement a loop that allows the user to input information for multiple
       students. Continue to add students until the user decides to exit.
    6. Create an array to store information for multiple students. You should be
       able to add, remove, and modify student records within this array.
    7. Implement functions for adding, modifying, and displaying student
       records. These functions should take appropriate arguments and return
       relevant information.
    8. Use dynamic memory allocation to allocate memory for the student
       records. Ensure you free the memory when it is no longer needed.
    9. Implement the ability to save student records to a text file and load
       student records from a text file. The file should store student
       information like name, roll number, and marks.

### Additional Features

    ● Allow users to search for a student by their roll number and display their
      information.
    ● Calculate and display the average marks for all students.
    ● Provide an option to sort the student records based on marks in
      ascending or descending order.

### Project Submission
Submit your C program along with a brief documentation explaining how to use
it. Make sure your code is well-organized, and you have used appropriate
comments and function headers.
